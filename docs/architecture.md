# Planned architecture

Every component below is planned and unimplemented in this scaffold.

| Planned component | Planned responsibility |
|---|---|
| CockroachDB memory | Persist proposals, evaluations, decisions, effects, and consequences |
| Distributed vector index | Retrieve semantically near precedent candidates |
| Read-only cluster adapter | Supply agent-consumed cluster information |
| Deterministic evaluator | Produce a four-valued result and sparse typed trace |
| Human interface | Record an independent human decision |
| Typed demo executor | Apply one bounded append-only demonstration effect |
| Consequence reporter | Append observed outcome evidence |
| AWS Lambda | Serve fixed read-only demonstration routes |
